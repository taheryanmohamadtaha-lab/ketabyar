# کتاب‌یار زندگی (KetabYar)
برنامه اندرویدی فارسی و راست‌چین برای مطالعه خلاصه کتاب‌ها.

## ساخت APK
1. همه فایل‌های این پوشه را در یک مخزن GitHub بارگذاری کنید (پوشه پنهان `.github` هم باید باشد).
2. در GitHub به تب **Actions** بروید، «Android Build» را انتخاب و **Run workflow** بزنید.
3. پس از پایان، از بخش **Artifacts** فایل `KetabYar-debug-apk` را دانلود و نصب کنید.

## افزودن کتاب
کتاب‌ها در `app/src/main/assets/content/catalog.json` قرار دارند؛ یک آیتم جدید با همان ساختار به آرایه `books` اضافه کنید.
